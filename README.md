### ⚡ About Me

I am an **AI Engineer & Systems Architect** specializing in autonomous multi-agent systems, intelligent model routing, and applied machine learning. With a background bridging creative design and engineering, I focus on building resilient, resource-efficient AI workflows that bridge theoretical research into production-grade systems.

- 🌟 **IBM SkillsBuild AI Scholar:** Completed an intensive 6-month AI Engineering specialization covering full-lifecycle ML/DL systems and end-to-end architectures.
- 🤖 **Multi-Agent Orchestration:** Architect of **Agent-Z Homelab**, a 24/7 self-hosted Linux server orchestrating autonomous sub-agents (Hermes Agent & OpenClaw) with dynamic proxy routing (9Router) and zero cloud idle costs.
- 🏆 **Quant & AI Hackathons:** 2x certified hackathon competitor on Lablab.ai — built **AutoOverlay AI** (Alpaca AI Trading Agents) with Merton Jump Diffusion Monte Carlo stress testing and **A2Z Agentz** (AMD Developer Hackathon: ACT II).
- 📄 **Published ML Researcher:** Co-authored and presented dynamic flight price prediction research using Multiple Linear Regression over 116k+ records at the peer-reviewed national conference **SISFOTEK 2026**.
- 🎓 **Undergraduate in Information Systems:** Current student at STMIK IKMI Cirebon (Cumulative GPA: 3.55 / 4.00), maintaining a continuous upward academic trajectory.

### 🚀 Featured Engineering Projects

#### 1. [AutoOverlay AI: Autonomous Options Trading & Quant Risk Agent](https://lablab.ai/ai-hackathons/alpaca-ai-trading-agents-hackathon/greyarch-syndicate/autooverlay-ai-autonomous-options-yield-agent)
> *Alpaca AI Trading Agents Hackathon • Cert ID: `CMU18DH64006FS601N2HPXF7S`*
- Engineered an autonomous multi-agent trading system integrating Alpaca Markets REST API with multi-persona LLM market sentiment and quantitative risk overlays.
- Built a **Pre-Trade Risk Manager (PTRM)** with automated kill-switches and **Merton Jump Diffusion Monte Carlo stress testing** (evaluating VaR-95 & Sortino ratio under jump-volatility shocks).
- Implemented OCC options contract resolution with strict mid-price limit order execution rules to prevent hallucinations and execution slippage.

#### 2. [Agent-Z Homelab: 24/7 Autonomous AI Agent Orchestrator](https://zmdinata.web.id)
> *Personal Production Infrastructure • Self-Hosted Linux Server*
- Repurposed a 10-year-old ThinkPad T440 laptop into an always-on, resource-constrained AI operations homelab server running Docker and Telegram-bridged control loops.
- Deployed a dual-agent architecture (**Hermes Agent** + **OpenClaw**) managing background sub-agents, memory pruning, and automated git synchronization.
- Configured dynamic fallback model routing via **9Router**, cutting API inference costs while maintaining high availability under limited RAM/CPU budgets.

#### 3. [A2Z Agentz: Autonomous Web3 Scavenger on AMD](https://lablab.ai/ai-hackathons/amd-developer-hackathon-act-ii/a2z-agentz/a2z-agentz-autonomous-web3-scavenger)
> *AMD Developer Hackathon: ACT II • Cert ID: `CMSR98H4404A9S601PBEY6U8K`*
- Architected telemetry dashboard and agent scoping boundaries for a dual-brain Web3 discovery agent targeting the Base network.
- Coordinated multi-tier reasoning between local inference (`Meta-Llama-3.1-8B` on AMD Instinct MI300X via vLLM) and heavy reasoning agents with strict per-transaction spend caps.
